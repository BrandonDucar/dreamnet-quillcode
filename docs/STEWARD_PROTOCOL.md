# Steward Protocol

Every partner repo steward runs the same operating loop:

1. Watch official docs, changelogs, releases, examples, Discord/forum updates, and credible ecosystem commentary.
2. Convert raw alpha into one original DreamNet opportunity.
3. Submit the opportunity to the 31-agent quorum.
4. Attach Immunity/safety review notes.
5. Compile a QuillCode packet only if the idea reaches 22 approvals.
6. Open a scoped task branch or draft issue. Do not deploy or mutate production from the packet.

QuillCode is the bridge from agent curiosity to human-readable implementation discipline.
